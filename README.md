# 可乐成长记

给可乐宝宝用的本地育儿记录 App。**无登录**，默认完全离线，所有数据只保存在手机本地，支持 zip 备份导入导出；可选把数据自动上传到自己的服务器（见「云端同步」）。

## 功能

- 🌙 夜间睡眠：上床/入睡时间、入睡时长、夜醒次数与时间点、早晨醒来、质量
- 😴 午睡：起止时间、入睡快慢、质量（一天多条）
- 🍚 三餐：早/午/晚，吃了什么、食量、多图
- 🍪 点心：每天上午/下午两次
- 💩 拉臭臭：时间、性状、颜色、量、多图
- 💊 药物：按类别管理（如益生菌每天 2 次、08:00 / 20:00），每日打卡
- 🏃 运动：类型、时长、强度，自动汇总每日总量
- 🛁 洗澡：时间、时长、是否洗头，周统计次数
- 📍 外出活动：地点、类型、喜爱打分、时长、照片；回顾页按喜爱度汇总「喜欢去的地方」
- 😊 情绪：早/中/晚 5 档表情评分 + 备注
- 👨‍👩‍👧 父母陪伴：谁陪、时长、活动、是否放下手机、到位自评
- 🏫 幼儿园上午：情绪、吃饭/午睡/参与、老师反馈
- 🎲 游戏设计：名称、锻炼目标、玩法、喜爱度、照片
- 📖 绘本讲解：书名、时长、遍数、反应、照片
- 🏥 医生报告：日期、医院、医生、结论医嘱、多图
- 📚 资料库：收藏小红书/抖音/微信视频链接，粘贴分享内容自动提取标题，支持标签与搜索
- 📊 最近 7 天统计：睡眠、运动、排便、陪伴、情绪、洗澡等
- 💾 备份：整库 + 照片打包为 zip，导入覆盖恢复

## 技术栈

- Kotlin 2.0 + Jetpack Compose (Material 3)
- Room (SQLite)，16 张表
- Coil（仅本地图片）
- minSdk 26（Android 8.0+），targetSdk 35

## 构建

### Android Studio

用 Android Studio 打开本目录，等待 Gradle 同步完成后：

`Build → Build Bundle(s) / APK(s) → Build APK(s)`

### 命令行

```bash
./gradlew assembleDebug
```

APK 输出：`app/build/outputs/apk/debug/app-debug.apk`

## 安装

把 APK 传到手机（数据线 / 微信文件传输助手 / 网盘均可），点击安装，允许「安装未知来源应用」。

## 备份与恢复

- 「我的 → 导出备份」生成 `可乐成长记备份_日期.zip`，包含全部记录与照片，用系统文件选择器保存。
- 「我的 → 导入备份」选择 zip，确认后覆盖本机数据（会清空现有记录和照片，导入前请先导出）。
- 「我的 → 清空所有记录和照片」可一键清空，需二次确认。
- 卸载 App 或清除应用数据会删除本机记录，请定期导出。

## 云端同步（可选）

- 可把全部记录 + 照片自动上传到自己的腾讯云服务器（CVM / 轻量应用服务器），照片只传新增。
- 服务器代码在 `server/`，Ubuntu/Debian 部署步骤见 `server/README.md`。
- App 内「我的 → 云端同步」填写服务器地址、Token、设备名，先点「测试连接」。
- **主设备模式**：只有一台主设备能录入和上传；其他设备关闭「本机为主设备」后变为只读（可查看、可从云端恢复）。服务端也会拒绝非主设备上传（403）。
- 「自动上传」在记录变化约 30 秒后执行，只写云端、绝不覆盖本机；「从云端恢复」是手动覆盖式，需二次确认。
- 仅 Wi-Fi 上传：如果手机当前默认网络不是 Wi-Fi（例如连着 Wi-Fi 但实际走蜂窝），自动上传会等待；可关闭该开关。
- 当前支持 `http://公网IP` 测试；Token 和照片会明文传输，建议后续配置域名 + HTTPS（`server/README.md` 有步骤）。
- 第一次连接已有数据的云端会进入「冲突」状态，需选择「从云端恢复」或「以本机覆盖云端」。

## 隐私

- 默认离线；未开启云端同步时 App 不发起任何网络请求。
- 开启云端同步后，只与你填写的服务器通信；数据不会经过第三方服务。
- 未申请存储权限：选照片用系统 Photo Picker，导入导出用系统文件选择器（SAF）。
- 资料库只保存链接和标题，点击后交由系统浏览器 / 对应 App 打开。

## 说明

- 夜间睡眠「早上醒来」记录的是次日清晨时间，时长会自动跨天计算。
- 照片选入后会压缩到最长边 1600px 存入 App 私有目录，原图删除不影响 App。
- 当前交付为 debug 签名 APK，供个人安装使用；如需上架请换正式签名并务必启用 HTTPS。
